## Design Consideration
Physically challenged people are not able to enjoy Table-Top games and the only constraint is rolling dice! I find it very stupid for all the technological advancements we have gone through.
And so, I have taken it upon myself along with my mentors at [RISC-V Ottawa (RVO)](https://riscvottawa.ca/) to help me build a fully open sourced dice for all.

If you feel like contributing to this project please familiarize yourself with the project and the repository!
