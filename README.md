# DICE

An open-source, accessible electronic dice roller built on RISC-V architecture. Designed in collaboration with [RISC-V Ottawa (RVO)](https://riscvottawa.ca/), this project removes physical barriers to tabletop gaming so everyone can roll D20s regardless of physical ability.


## About the Project

Physical tabletop games (like D&D, Pathfinder, and classic board games) rely heavily on physical dice rolls. For many players with motor disabilities or physical challenges, rolling traditional dice can be a significant barrier.

## Getting Started
### Prerequisites
- KiCad for PCB design
- Rust toolchain with `riscv32imac-unknown-none-elf` target
- An ESP-32-C3 as this projcect is being developed on one
- ADXL-345 the primary sensor
